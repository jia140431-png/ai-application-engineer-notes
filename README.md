## 怎么复习

第一轮：按模块阅读，能画出模型生成、RAG、工具循环和审批恢复四条链路。

第二轮：合上笔记回答每个单元的问题，再用模块末尾的答案检查概念边界。

第三轮：按面试题进行 2 分钟口述。用“原理 → 取舍 → 失败场景 → 验证方法”组织答案。可以纸上推演，不需要为了复习新建编码项目。
