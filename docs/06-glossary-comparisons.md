# 关键术语与对比

[返回目录](../README.md) · 来源：补充复习。

## 术语速查

| 术语 | 含义 | 易错点 |
|---|---|---|
| Token | 模型处理的离散单元 | 不等于字或字符 |
| Embedding | 文本等对象的向量表示 | 相似度不是正确率 |
| Context Window | 单次处理的上下文容量 | 不等于跨会话永久记忆 |
| Hallucination | 缺乏依据或不符合事实的生成 | 低温度不能彻底解决 |
| SFT | 用指令及期望输出训练行为 | 不是实时知识同步 |
| Prefill / Decode | 处理输入 / 逐步生成输出 | 对延迟影响不同 |
| TTFT | 到首个输出的时间 | 不代表整段完成时间 |
| P95 | 95% 样本不超过的观测值 | 均值不能描述尾部体验 |
| RAG | 检索外部材料辅助生成 | 不自动保证答案有依据 |
| Chunk | 检索或组装使用的文档片段 | 条件与结论不能随意切开 |
| ANN | 近似最近邻搜索 | 向量近邻不等于业务相关 |
| Reranker | 对候选进行更精细排序 | 不能补回没召回的候选 |
| Grounding | 使回答受证据支撑 | 有引用不等于引用支持结论 |
| State | 当前任务的数据与进度 | 不只是聊天历史 |
| Checkpoint | 为恢复保存的执行状态 | 不保证外部动作只执行一次 |
| Idempotency | 重复同一业务操作不重复产生效果 | 不等于不发生重试 |
| HITL | 在流程中引入人类输入或决策 | 确认应绑定具体操作版本 |
| Trace / Span | 一条链路 / 其中一个执行片段 | 必须能关联阶段输入输出 |
| MCP / A2A | 外部能力连接 / Agent 间互操作协议 | 不提供完整业务事务 |

## 技术取舍表

| 比较 | 前者适合 | 后者适合 | 判断依据 |
|---|---|---|---|
| Prompt / 微调 | 快速表达任务与证据规则 | 稳定学习行为模式 | 数据、效果与维护成本 |
| RAG / 微调 | 更新事实、引用来源 | 任务风格与行为 | 改的是知识还是行为 |
| 关键词 / 向量 | 精确编号、术语 | 同义改写与语义匹配 | 用真实问题验证 |
| Retriever / Reranker | 广泛找候选 | 精细排序候选 | 证据在哪一步丢失 |
| Workflow / Agent | 路径明确 | 动态选择动作 | 不确定性是否需要模型处理 |
| 单 Agent / 多 Agent | 责任集中、协调简单 | 专业边界或并行收益明确 | 收益能否抵消协调成本 |
| Checkpoint / 幂等 | 恢复执行进度 | 防重复业务效果 | 两者通常都需要 |
| 事务回滚 / 补偿 | 同一事务内撤销 | 跨系统执行反向业务动作 | 外部动作是否可逆 |

## 评估指标口径

以下是学习用定义，项目应固定自己的标注和实现。

| 指标 | 常见定义 | 限制 |
|---|---|---|
| Recall@K | TopK 命中的相关项数 / 全部标注相关项数 | 未知完整相关集时分母难确定；单证据命中率应另行说明 |
| Precision@K | TopK 中相关项数 / K | 需说明不足 K 项时如何处理 |
| MRR | 每题首个相关项名次倒数的均值 | 忽略后续相关项 |
| NDCG@K | DCG@K / 理想排序 DCG@K | 必须说明相关等级与无相关项处理 |
| Context Precision | 上下文中相关证据的精确程度 | 不同评估工具口径可能不同 |
| Faithfulness | 回答声明受提供证据支持的程度 | 证据本身可能错误 |
| Answer Correctness | 回答满足正确答案或标准的程度 | 需允许等价表述、澄清和合理拒答 |

常见 DCG 为 `Σ(2^rel_i - 1) / log2(i + 1)`。没有相关标签的问题不宜直接塞进普通 Recall 分母，可单独评估无答案识别。

示例：某题有 2 个标注相关片段，Top5 命中 1 个，则 Recall@5 = 1/2，Precision@5 = 1/5。即使命中的片段足以回答，片段召回指标也不能自动等同最终答案得分。
